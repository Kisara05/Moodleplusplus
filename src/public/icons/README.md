# Icons Directory

Place your PNG icon files in this directory. The following icons are expected:

- `help.png` - Help/question mark icon (white on transparent background)
- `bell.png` - Notifications bell icon (white on transparent background)
- `message.png` - Messages/speech bubble icon (white on transparent background)
- `search.png` - Search/magnifying glass icon (dark gray/black)
- `chevron-down.png` - Dropdown chevron icon (white on transparent background)

## Icon Specifications

- **Size**: Recommended 24x24px to 32x32px
- **Format**: PNG with transparency
- **Color**: 
  - Help, Bell, Message, Chevron: White (#FFFFFF) for use on teal background
  - Search: Dark gray (#565656) or black for use in search bar
- **Border Radius**: Icons will be displayed in containers with 25px border radius

## Fallback

If icons are not found, the application will fall back to emoji/text representations:
- Help: "?"
- Bell: "🔔"
- Message: "💬"
- Search: "🔍"
- Chevron: "▼"
